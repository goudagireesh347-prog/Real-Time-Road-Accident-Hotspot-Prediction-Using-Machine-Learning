Project Architecture & Pipeline

The system implements an end-to-end data science and full-stack software engineering architecture:

1. Storage & Persistence

MySQL / SQLAlchemy persistent store with indexing on latitude, longitude, dates, and risk levels.

2. Geospatial Processing

GeoPandas spatial point mapping, CRS projection (EPSG:4326), and density grouping.

3. Machine Learning Model

Scikit-learn Random Forest Classifier trained with 120 estimators, balanced weights, and feature importance analysis.

4. Interactive Cartography

Folium, HeatMap, and CircleMarker visual layers with live scenario risk overlays.
